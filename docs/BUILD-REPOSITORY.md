# 构筑文档与草稿存储基础

src/core/build-repository.js 是独立存储层，尚未接入 Electron IPC、现有 Store 或玩家界面，不会改写现有角色存档。

每个角色的当前文档包含持久化 revision、PoB2 XML、装备覆盖和武器组；草稿固定 baseRevision，编辑只增加草稿版本。采用草稿必须同时匹配当前版本与草稿版本，并由调用方提供引擎校验函数；仅明确 pass 且带引擎指纹的结果允许持久化。该回调是业务接入契约，不表示本模块已经完成真实引擎草稿试算。

写入使用目录内排他 lock、重新读取、临时文件和原子重命名。另一实例遇到锁会明确拒绝，不抢写；损坏文件不以默认值覆盖；校验失败保留原文档与草稿。最近 30 个先前版本保存在同一文档中，为后续恢复接口提供数据。异常进程可能留下锁文件，当前会安全拒写，尚无自动回收旧锁机制。

6 项新增测试验证重启后持久化、草稿隔离、版本冲突、校验失败不落盘、多实例并发拒绝、损坏文件保护和保留键限制。下一步为引擎草稿试算适配器、现有业务导入/采用入口和完整事务失败回归；目前不对用户开放孤立的存储层入口。
