# P1：计算上下文与引擎事务

2026-11-03，基线 a5a2815。本阶段保留现有 PoB v0.23.1，不宣称原生逐技能双组已支持。

## 已交付

- calculation-context：不可变请求归属，在异步前后校验角色、构筑代次和计算设置。
- operation-queue：串行执行完整事务；排队取消不执行；运行中取消保持引擎租约直到安全收尾。
- 引擎公共计算接口经过队列。transaction(callback, {signal}) 给回调一个不再次排队的 engine facade。回调应顺序 await facade；不要从回调调用外层公共计算接口，以免等待自身。
- 角色面板“加载→按主技能对齐武器组→读取面板”、手动切组“加载→切组→读取主技能→标记组”分别作为完整事务执行。
- 失败或运行中取消时丢弃活动进程，清除摘要；下一操作从记录的 XML、覆盖装备和武器组重载。旧构筑排队任务在启动前被拒绝。
- load 的覆盖装备和目标武器组在调用时快照；覆盖装备或恢复武器组失败会明确报错，不返回假成功。
